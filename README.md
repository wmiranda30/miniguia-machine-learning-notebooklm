# Machine Learning aplicado à Análise de Dados e Tomada de Decisões
Projeto desenvolvido como parte de um desafio prático da DIO, utilizando o NotebookLM como ferramenta de aprendizagem ativa, organização do conhecimento e experimentação com Inteligência Artificial.

## 📌 Contexto e Objetivos

O tema escolhido para este projeto foi **Machine Learning aplicado à Análise de Dados e Tomada de Decisões**.

A escolha do tema teve como objetivo compreender como técnicas de aprendizado de máquina podem ser utilizadas para analisar dados, identificar padrões, realizar previsões e auxiliar pessoas e organizações na tomada de decisões baseadas em dados.

Os principais objetivos de estudo foram:

- Compreender os fundamentos de Machine Learning;
- Entender a relação entre Machine Learning e análise de dados;
- Diferenciar aprendizagem supervisionada e não supervisionada;
- Conhecer algumas aplicações práticas dos algoritmos;
- Entender como modelos preditivos podem apoiar decisões;
- Analisar limitações, riscos e questões éticas relacionadas ao uso de algoritmos.

# 📖 Miniguia de Estudo

## O que é Machine Learning?

Machine Learning, ou Aprendizado de Máquina, é uma área da Inteligência Artificial que utiliza dados e métodos matemáticos e estatísticos para desenvolver modelos capazes de identificar padrões e realizar previsões.

Em vez de depender apenas de regras programadas manualmente, os algoritmos podem aprender relações existentes nos dados utilizados durante o treinamento.

---

## Machine Learning e Análise de Dados

A análise de dados envolve processos como coleta, organização, limpeza, transformação e interpretação de informações.

Machine Learning pode complementar esse processo identificando padrões mais complexos e construindo modelos capazes de realizar classificações, previsões e agrupamentos.

Dessa forma, dados históricos podem ser utilizados para gerar informações que auxiliam decisões futuras.

---

## Aprendizagem Supervisionada

A aprendizagem supervisionada utiliza **dados rotulados**, ou seja, dados em que o resultado esperado já é conhecido durante o treinamento.

É utilizada principalmente em:

- Classificação;
- Regressão;
- Previsões.

Alguns exemplos de algoritmos:

- Regressão Linear;
- KNN;
- Árvore de Decisão;
- Random Forest;
- Naive Bayes;
- SVM.

---

## Aprendizagem Não Supervisionada

A aprendizagem não supervisionada utiliza **dados sem rótulos previamente definidos**.

O objetivo é encontrar estruturas, semelhanças ou padrões ocultos nos dados.

Pode ser utilizada para:

- Agrupamento;
- Detecção de padrões;
- Associação;
- Redução de dimensionalidade;
- Identificação de anomalias.

Alguns exemplos:

- K-means;
- DBSCAN;
- PCA;
- Regras de associação.

---

## Aplicações Práticas

Machine Learning pode ser aplicado em diferentes áreas.

Exemplos:

- Sistemas de recomendação;
- Previsão de demanda;
- Gestão de estoques;
- Identificação de padrões de consumo;
- Previsão de desempenho;
- Detecção de anomalias;
- Apoio a decisões empresariais.


## Machine Learning na Tomada de Decisões

Modelos de Machine Learning podem transformar grandes volumes de dados em informações úteis.

Com isso, organizações podem utilizar dados históricos para:

- Realizar previsões;
- Reduzir incertezas;
- Identificar tendências;
- Otimizar processos;
- Apoiar decisões estratégicas.

Entretanto, os resultados dos modelos não devem ser utilizados sem análise crítica.


## ⚠️ Riscos e Limitações

Modelos de Machine Learning dependem diretamente da qualidade dos dados utilizados.

Dados incompletos, enviesados ou inadequados podem produzir resultados incorretos ou injustos.

Por isso, alguns pontos importantes são:

- Qualidade dos dados;
- Transparência;
- Governança;
- Identificação de vieses;
- Privacidade;
- Supervisão humana.

A utilização responsável de Inteligência Artificial exige que os resultados dos algoritmos sejam analisados criticamente.


# 📘 Glossário

**Machine Learning:** área da Inteligência Artificial que desenvolve modelos capazes de aprender padrões a partir de dados.

**Algoritmo:** conjunto de instruções ou procedimentos utilizados para resolver determinado problema.

**Modelo:** representação criada após o treinamento de um algoritmo com dados.

**Dados rotulados:** dados que possuem uma resposta ou categoria previamente conhecida.

**Dados não rotulados:** dados que não possuem uma resposta previamente definida.

**Aprendizagem supervisionada:** técnica em que o modelo aprende utilizando exemplos com respostas conhecidas.

**Aprendizagem não supervisionada:** técnica utilizada para encontrar padrões em dados sem respostas previamente definidas.

**Classificação:** tarefa utilizada para prever categorias.

**Regressão:** técnica utilizada para prever valores numéricos.

**Clustering:** processo de agrupamento de dados com características semelhantes.

**Análise preditiva:** utilização de dados históricos e modelos para estimar acontecimentos futuros.

**Viés algorítmico:** distorção nos resultados de um algoritmo causada, entre outros fatores, pelos dados utilizados no treinamento.
